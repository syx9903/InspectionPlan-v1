# Text Page 文本质量特征分析

## 1. 问题背景

现有 Page 路由使用 `中文、英文、数字有效字符 >= 20 → Text`。TASK-002.8 已发现
乱码、水印和流程图伪文本都可能超过20字符，因此本次只分析已有 Text Page 的
简单确定性特征，为后续离线判定 baseline 提供依据。本任务不评价 OCR，不修改
路由，也不把人工工程抽检标签称为正式 Gold。

## 2. 当前样本

使用 TASK-002.8 的12个 `parse_method=text` 样本：

| 标签 | 数量 |
| --- | ---: |
| good | 4 |
| acceptable | 1 |
| bad | 7 |

标签已人工视觉复核，但 `labels_are_user_confirmed=false`。样本刻意覆盖失败边界，
只能用于 baseline 探索，不能估计全库质量或证明阈值泛化能力。

## 3. 候选特征定义

### 长度

- `char_count`：Python `len(text)`，包含空白。
- `non_whitespace_count`：非空白字符数。
- `effective_char_count`：严格沿用现有20字符口径，即 CJK 扩展A/基本汉字、
  ASCII A～Z/a～z 和0～9。

### 字符组成

- `chinese_count`：CJK 扩展A及基本统一汉字区字符数。
- `latin_count`：Unicode 名称属于 LATIN 的字母数，包含 ASCII 与扩展 Latin。
- `digit_count`：Unicode 十进制数字数。
- 三个 ratio：分别除以上三类之和；空分母返回0。

### 可疑字符

`suspicious_char_count/ratio` 使用透明规则，不使用庞大黑名单。以下字符可疑：

- Unicode replacement character `�`；
- 除换行、回车、制表外的控制或格式字符；
- 私用或未分配字符；
- 不可打印的非空白字符；
- 非 ASCII 的扩展 Latin 字母，例如乱码样本中的 `î/ï/ð`。

ratio 分母为非空白字符数。

### 可读字符

`readable_char_count/ratio` 把中文、ASCII 字母数字、Unicode 十进制数字、ASCII
标点和明确列出的常用中文/全角标点视为可读。ratio 分母为非空白字符数。
该定义只是字符集合覆盖率，不是语言可读性分数；形似乱码的合法 CJK 字符仍可能
被计为可读。

### 行结构与重复

- `line_count`：`splitlines()` 后总行数。
- `non_empty_line_count`：去除纯空白行后的行数。
- `average_line_length/max_line_length`：非空行的非空白字符长度均值/最大值。
- `repeated_line_ratio`：重复的非空行实例数除以非空行数。

表格中的三元组依次为 min / median / max。

### 较有价值的信号

- `suspicious_char_ratio > 0`：命中4/7 bad、0/5 good/acceptable。适合识别扩展
  Latin、控制/私用等明确乱码证据，但遗漏纯中文伪文本。
- `readable_char_ratio < 0.9`：同样命中4/7 bad、0/5非 bad；与 suspicious 高度
  相关，适合补充解释字符集合异常。
- `chinese_ratio < 0.7`：命中6/7 bad、0/5非 bad；但中文比例本身不是质量保证，
  PQ-005 达到1.0仍为 bad。
- `effective_char_count < 200` 与 `average_line_length < 20` 在当前12页上都恰好
  命中7/7 bad、0/5非 bad。这是强烈的小样本分界，但合法短标题、目录或附录页
  很可能产生假阳性，只能作为“需进一步检查”的覆盖率代理。

### 不能单独使用的信号

- `chinese_ratio`：bad 范围0.062～1.0，与正常中文正文完全重叠。
- `readable_char_ratio`：PQ-005 为1.0，PQ-020/021约0.981，字符集合看似正常但
  页面主体缺失。
- `suspicious_char_ratio`：3个 bad 为0，无法捕捉合法字符组成的水印/伪文本。
- `line_count`：PQ-015 有114个非空行，高于所有 good，表格乱码反而行数更多。
- `repeated_line_ratio`：多数样本为0，仅 PQ-015/PQ-016 有少量重复，覆盖不足。
- 任何单一长度阈值：当前分离漂亮，但样本太小且缺少合法短正文对照。

## 7. 仅靠纯文本无法解决的正文覆盖率

仅依赖提取后的 text，不能可靠判断原页面正文大量缺失。PQ-005 的文本是：

```text
山东省特种设备检验研究院集团有限公司
内部收藏
```

它在语言上完全合法，因此中文比例1.0、可疑比例0、可读比例1.0。纯文本不知道
原 PDF 还有标准号、标题、发布日期和发布机构。低长度可以提示风险，但也可能是
合法短标题或空白过渡页，无法证明“覆盖率低”。

同理，流程图页的少量标题、水印或标引文本也可能全部合法。要直接衡量覆盖率，
至少需要页面图像/文本框面积、图像占比或版面信息；这些超出本任务范围。

## 8. 下一任务候选组合规则

以下只作为 TASK-002.9.2 的离线候选，不是正式判定，也未接入 Router：

1. 明确乱码证据：`suspicious_char_ratio > 0`。
2. 字符集合异常：`readable_char_ratio < 0.9`。
3. 组成异常：`chinese_ratio < 0.7`，需与 Latin/suspicious 联合验证。
4. 覆盖率风险代理：`effective_char_count < 200 AND average_line_length < 20`；只应
   标记为可疑并重点测试合法短页假阳性。
5. 候选组合：明确乱码证据 OR（低有效字符且短平均行）。下一任务应报告混淆矩阵，
   并扩大正常短页、封面、目录、表格和 mixed 页样本后再确定阈值。
